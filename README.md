# Судоку — спокойная игра (PWA)

Судоку 9×9 с 9 уровнями сложности, мягкими анимациями, наградами и работой без интернета.
Без сборки и зависимостей — чистые HTML/CSS/JS.

## Уровни
Сложность = сколько цифр открыто в начале (у каждой головоломки ровно одно решение):

| Уровень | Название | Открыто цифр |
|---|---|---|
| 1 | Первые шаги | 52 |
| 2 | Очень лёгкий | 47 |
| 3 | Лёгкий | 43 |
| 4 | Спокойный | 39 |
| 5 | Средний | 35 |
| 6 | Вдумчивый | 32 |
| 7 | Сложный | 29 |
| 8 | Очень сложный | 26 |
| 9 | Мастер | 24 |

## Награды
Считаются **исправления уже поставленных цифр**: замена цифры, стирание, «Отменить» после постановки, подсказка. Заметки не считаются.

| Исправлений | Награда |
|---|---|
| 0 | Хрустальная корона |
| 1–2 | Золотая медаль |
| 3–5 | Серебряная медаль |
| 6–10 | Бронзовая медаль |
| 11+ | Орден терпения |

Значок текущей награды виден в шапке во время игры. Прогресс и награды хранятся в браузере (localStorage), незаконченная игра сохраняется автоматически.

## Публикация на GitHub Pages
```bash
git init
git add .
git commit -m "Sudoku PWA"
git branch -M main
git remote add origin https://github.com/<логин>/sudoku.git
git push -u origin main
```
Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту игра будет на `https://<логин>.github.io/sudoku/`.

Все пути относительные, поэтому работает и в подпапке, и на своём домене.

## Установка на рабочий стол
- **Компьютер (Chrome / Edge):** открыть сайт → значок «Установить» справа в адресной строке (или кнопка «Установить на рабочий стол» в меню игры).
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран „Домой“».

## Обновление
После изменения файлов увеличьте `VERSION` в `sw.js` — тогда у бабушки подтянется новая версия при следующем запуске (иногда нужно открыть игру дважды).

## Структура
```
index.html             разметка экранов
css/style.css          стили и анимации
js/sudoku.js           генератор/решатель (уникальное решение)
js/fx.js               звуки, конфетти, медали
js/app.js              логика игры
sw.js                  офлайн-кэш
manifest.webmanifest   PWA-манифест
icons/                 иконки (SVG + PNG, maskable, apple-touch)
```

## Управление с клавиатуры
Стрелки — выбор клетки, 1–9 — цифра, Delete/Backspace — стереть, N — заметки, Ctrl+Z — отменить.
