# Судоку — спокійна гра (PWA)

Судоку 9×9: 12 рівнів, нагороди, святкові анімації, великі цифри, працює без інтернету.
Без збирання і залежностей — усе в одному `index.html`.

## Нагороди
Рахуються **виправлення вже поставлених цифр**: заміна, стирання, «Скасувати» після ходу, підказка. Нотатки не рахуються.

| Умова | Нагорода |
|---|---|
| не більше 1 виправлення **і швидше 10 хвилин** | 💎 Діамантовий кубок (найвища) |
| не більше 1 виправлення | Золота корона |
| 2–3 | Золота медаль |
| 4–6 | Срібна медаль |
| 7–10 | Бронзова медаль |
| більше 10 | Орден терпіння |

## Секрет: Ідеальне рішення
Для кожної гри заздалегідь рахується «ідеальна» послідовність ходів (щоразу найочевидніша клітинка).
Якщо перші 3 ходи гравця точно збігаються з нею, решта цифр з'являється сама, по одній кожні 0.2 с,
і гравець отримує секретну нагороду **Ідеальне рішення** з окремою святковою анімацією.
Помилка, стирання, «Скасувати» чи підказка вимикають цю можливість у поточній грі. Нотатки не заважають.
Після такої перемоги наступні 19 ігор цей механізм вимкнений, тож нагорода випадає не частіше 1 разу на 20 ігор.

## Продовження гри
Гра зберігається після кожного ходу. Якщо закрити застосунок, при наступному запуску з'явиться вікно «Продовжимо?».

## Розмір цифр (Налаштування)
- **Звичайний** — поле з відступами.
- **Великий** — поле до країв екрана (1px), цифра на всю клітинку.
- **Максимум** — до країв і витягнуте у висоту.

У всіх режимах цифра малюється з відступом ~1px від краю клітинки.

## Публікація на GitHub Pages
1. Видаліть у репозиторії всі старі файли.
2. Add file → Upload files → усі файли з архіву → Commit changes.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–2 хвилини: `https://<логін>.github.io/<репозиторій>/`.

## Встановлення на робочий стіл
Відкрийте гру → **Налаштування** → «Встановлення на робочий стіл» → **Встановити застосунок**.
Там же видно, чи всі файли на місці. Або: Chrome → ⋮ → «Встановити застосунок».

## Оновлення
Після змін збільште `VERSION` у `sw.js`, інакше старі файли лишаться в кеші.
