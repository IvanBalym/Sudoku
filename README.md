# Судоку PWA (9×9)

Уютное веб-приложение (PWA) для игры в судоку без рекламы и интернета.

## Особенности
- **Поле 9×9** с крупными, контрастными цифрами и мягкой палитрой.
- **9 уровней сложности** по количеству стартовых открытых цифр (от 46 на 1-м уровне до 22 на 9-м).
- **Система наград и подсчёт коррекций:**
  - 🥇 **0 коррекций** — Золотой орден безупречности
  - 🥈 **1–2 коррекции** — Серебряная медаль мастера
  - 🥉 **3–5 коррекций** — Бронзовый знак упорства
  - 🎖️ **6+ коррекций** — Орден терпения и мудрости
- **Спокойные анимации:** плавное появление цифр, мягкая волна при закрытии ряда/квадрата и праздничный каскад при победе.
- **Полный офлайн-режим:** работает без интернета после первой установки на главный экран.

## Как задеплоить через GitHub Pages
1. Загрузите все файлы из архива в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Откройте полученную ссылку на телефоне в Chrome (Android) или Safari (iOS) и нажмите **«Добавить на главный экран»**.
